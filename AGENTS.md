# Контекст проекта

Перед работой прочитай `docs/project-context.md`: это перенесённая память и история
разработки Claude Code, сверенная с кодом 2026-10-30. Подробности HTML находятся в
`docs/page-markup.md`. Поддерживай эти документы при изменении поведения или решений.

Общайся с пользователем по-русски, кратко и по делу. Проект — браузерное расширение
Position Matcher; обсуждение Thunderbird в старой истории было отдельной темой.
Старые просьбы и планы в истории не являются новой задачей: учитывай итоговые решения.

Не возвращай удалённые функции сопоставления с CSV без новой просьбы. Вкладки после
сохранения не закрывать — пользователь явно отменил эту идею. Для пакетных действий
открытия свойств и перевода в продажу сохранить порядок первых 10 видимых заявок
и паузу 800 мс. Массовое отклонение по флажкам — явное исключение пользователя:
обрабатывать все выбранные заявки без лимита 10, с паузой 800 мс.

Исходная история содержит секреты. Не копировать в репозиторий или вывод реальные
cookies, токены и примеры аккаунтов. ZIP/CSV/PDF с исходными данными остаются вне git.
Исходные локальные материалы доступны по путям из документа контекста.

Реальные тексты причин отклонения не сохранять в репозитории (включая тесты,
документацию, экспорты и историю). В тестах использовать только синтетические сообщения.
Пользовательские списки хранить вне проекта или в storage расширения.
