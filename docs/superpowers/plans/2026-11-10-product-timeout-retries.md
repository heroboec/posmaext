# Повторы загрузки товаров

Утверждено пользователем в чате: максимум 3 попытки при таймауте, общая очередь
с минимум 1000 мс между стартами, без блокировки других поставок; отмена
останавливает повторы, после исчерпания доступен ручной повтор. Social Check
и смену статусов автоматически не повторять.

**Подход:** локальный цикл в `load(item)` мастера, не общий retry для POST.
Таймаут чтения JSON также должен сохранять свой тип. Полные строки только в памяти.
