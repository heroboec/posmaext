Position Matcher — Настройки

URL-паттерны
Панель фильтров появится только на страницах, URL которых содержит хотя бы один паттерн. По одному на строку.
Причины отклонения
Список изначально пуст. Одна причина — одна строка. Для короткого названия: «Название | Полный текст причины». Вместо « | » можно использовать табуляцию (два столбца из таблицы). Вставьте список или загрузите текстовый файл .txt в UTF-8. Пустые строки пропускаются.
В списке показывается короткое название, партнёру отправляется только полный текст. Строки без названия тоже поддерживаются. Список используется при одиночном и массовом отклонении. Перед отправкой текст можно изменить. Пустой список оставит только ручной ввод.

Загрузка файла заменяет текст в поле. Нажмите «Сохранить», чтобы применить изменения.
